# Glass One Launcher

Launcher Android ispirato al linguaggio visivo liquid/frosted glass, pensato per Galaxy S25 Ultra e Android 12+.

## Funzioni
- Launcher HOME reale
- Wallpaper di sistema dietro l'interfaccia
- Dock traslucido glass
- Griglia app
- App drawer e ricerca
- Mini Control Center
- Regolazione opacità, raggio angoli e dimensione icone
- Light/Dark automatico

## APK
La GitHub Action inclusa in `.github/workflows/build-apk.yml` compila automaticamente `app-debug.apk` e lo pubblica come artifact `GlassOneLauncher-debug-apk`.
