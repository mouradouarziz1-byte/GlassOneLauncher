# Arabia TV

Native Android app with an editorial directory of 64 Arab and international TV channels, Arabic/Italian UI, HLS player, favorites, history and local M3U import.

Source: `ArabiaTV-Android-sorgenti.zip` (SHA-256 f47dd8dc87e90324dcabc89d2654b03f46ea27cfcf1880793b9ee8d51ef50e81).

The dedicated workflow builds and signs a debug APK, probes public streams and runs unit, lint and Android emulator smoke tests. See the run for actual results. Unsupported live streams open the official broadcaster instead. This is a selected directory, not every existing channel; broadcaster rights and territory restrictions apply.
